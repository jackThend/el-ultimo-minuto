# El último minuto

Una máquina expendedora vende los últimos minutos de las cosas. Hoy ofrece el tuyo.

**[Leer o escuchar el cuento](https://jackthend.github.io/el-ultimo-minuto/)**

Un cuento interactivo muy corto: una decisión y dos finales. Ilustraciones de cómic lofi y narración sintética en español, con una voz dulce y cercana. Se recomienda usar auriculares.

Abre el enlace en el navegador del teléfono o del ordenador, pulsa **Comenzar** y elige leer o entrar en **Audio-drama sin pantalla**. El modo audio incluye botones táctiles para elegir, repetir, silenciar y volver a la lectura. No hace falta cuenta ni instalación.

Después de cargar todos los recursos, la aplicación permite leer sin conexión y añadir un acceso a la pantalla de inicio desde un navegador compatible.
